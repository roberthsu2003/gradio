# 🧱 使用 Blocks 類別建構靈活 UI

相較於簡易的 `gr.Interface`，使用 `gr.Blocks` 類別可以讓您自由控制組件的排列方式、自訂排版結構，並支援多組件之間複雜的事件監聽與資料傳遞。

---

## 📂 Blocks 系列專題

1.  **[Blocks 基礎與事件監聽者 (Blocks & Event Listeners)](./blocks_and_event_Listeners)**：開始學習 `gr.Blocks` 的運作架構與基本點擊事件綁定。
2.  **[版面控制 (Controlling Layout)](../controlling_layout)**：掌握 Row、Column、Tab 以及 Accordion 等排版元件。
3.  **[保存 Blocks 狀態 (State in Blocks)](../state_in_block)**：學習如何在 Blocks 的事件流程中操作 `gr.State` 儲存個人狀態。
4.  **[動態組件渲染 (Dynamic Apps With Render Decorator)](../dynamic_number_of_components)**：掌握 `@gr.render` 動態渲染 UI 的進階技巧。
5.  **[更多 Blocks 功能 (More Blocks Features)](../more_blocks_features)**：認識定時任務、資料收集 `gr.SelectData` 等進階事件處理。
